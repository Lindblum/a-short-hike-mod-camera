Third-party software included in ShortHikeCamera-<version>-with-BepInEx.zip
===========================================================================

This package includes an unmodified copy of BepInEx 5.4.23.2 (win x86), the
official release from:
  https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.2

The only addition to it is BepInEx\config\BepInEx.cfg, which sets
HideManagerGameObject = true (A Short Hike needs this to load plugins).

BepInEx and the libraries it ships are listed below with their licenses. The
full license texts are in this folder. Source code for each is available at
the address given.
